# FisioAsma IA — Fisiopatología experta

Aplicación centrada exclusivamente en fisiopatología del asma, basada en:
- Presentación1asma.pdf
- Fisiopatologia_Asma_Articulo_CBV.pdf

Banco: 40 preguntas, 10 por nivel.
Nivel 1: Comprender.
Nivel 2: Aplicar.
Nivel 3: Analizar.
Nivel 4: Evaluar casos fisiopatológicos integrados.

Ejes: inflamación T2, mediadores, respuesta inmediata/tardía, broncoconstricción,
edema, moco, hiperreactividad, limitación espiratoria, hiperinsuflación dinámica,
auto-PEEP, desventaja diafragmática, V/Q, hipoxemia, PaCO₂, fatiga y remodelado.

Se excluyen como eje principal diagnóstico, farmacología y manejo kinésico para
evitar diluir el dominio de fisiopatología.
